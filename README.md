# 선행 연구 정리 도구

논문을 검색하고, 마음에 드는 논문을 담아서 정리하고, 선행 연구 정리표를 엑셀로 내보내는 웹 도구입니다.
설치할 것이 없고, 브라우저에서 `index.html`을 열기만 하면 바로 쓸 수 있어요.

## 기능

- **논문 검색**: 전 세계 학술 논문 2억 건 이상을 검색해요 ([OpenAlex](https://openalex.org), 무료).
  - 연도 범위 지정, 관련도순 / 인용 많은 순 / 최신순 정렬, 무료 원문만 보기
- **내 목록**: 검색한 논문을 담아 두고 정리해요.
  - 상태(읽을 예정 / 읽는 중 / 읽음 / ⭐ 핵심)와 태그를 붙이고, 연구 목적·방법·결과·시사점을 메모해요.
  - 검색에 안 나오는 논문(국내 학위논문 등)은 **직접 추가**할 수 있어요.
  - APA 인용문 복사
- **정리표**: 담은 논문이 연도순으로 정리된 표가 만들어져요. 칸을 클릭해서 바로 수정할 수 있어요.
  - **엑셀(CSV)**, **BibTeX**(EndNote·Zotero·LaTeX용)로 내보내기
  - **백업 저장 / 불러오기**(JSON)

## 사용 방법

1. `index.html` 파일을 브라우저(크롬, 엣지, 사파리)로 엽니다.
2. **논문 검색** 탭에서 키워드를 입력하고 검색합니다.
3. 필요한 논문의 **+ 내 목록에 담기**를 누릅니다.
4. **내 목록** 탭에서 **✏️ 정리하기**를 눌러 내용을 정리합니다.
5. **정리표** 탭에서 표를 확인하고 엑셀로 내보냅니다.

> 정리한 내용은 지금 쓰고 있는 브라우저에 저장돼요. 다른 컴퓨터로 옮기거나 브라우저 기록을 지우기 전에는 **백업 저장**을 눌러 파일로 보관하세요.

## 인터넷 주소로 쓰기 (GitHub Pages)

1. GitHub 저장소에서 **Settings → Pages**로 들어갑니다.
2. **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://<아이디>.github.io/my-project/` 주소에서 쓸 수 있어요.
