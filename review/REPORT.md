# 선행연구 검토 보고서 — 2027년 천안시 유기·유실동물 구조(포획) 용역

- 기준 문서: 「2027년 천안시 동물보호센터 유기·유실동물 구조(포획) 용역 과업지시서」(천안시 축산과)
- 실행일: 2026-11-27 · 검색 기간: 2010–2026년 발표 논문
- 실행 방법: `node review/run_review.mjs` → `node review/audit.mjs` (Node 22, 프록시 환경에서는 `NODE_USE_ENV_PROXY=1`)

## 1. 검토 방법

GitHub에는 선행연구 검토 알고리즘의 "공인 권장안"이라 부를 만한 저장소가 없었어요. 검색된 저장소(MetaScreener, prisma-review-tool, hallmark, citeguard 등)는 대부분 개인 프로젝트였지만, 공통적으로 **PRISMA 2020**(체계적 문헌고찰 보고 지침)을 따르고 **DOI·서지 DB 대조로 인용 환각을 걸러내는 방식**을 쓰고 있었어요. 이 검토는 그 공통 원칙을 따랐고, 특정 저장소의 코드를 가져다 쓰지는 않았어요.

| 단계 | 내용 |
|---|---|
| 1. 식별 | OpenAlex에서 과업 관련 검색어 13개로 검색(검색어별 관련도 상위 50건) |
| 2. 중복 제거 | DOI(없으면 정규화한 제목) 기준 |
| 3. 기본 자격 | DOI 있음, 철회 아님, 학술논문(article/review), 초록 40단어 이상, 저자 정보 있음 |
| 4. 주제 선별 | 제목+초록에 ①유기·보호·구조 ②개·고양이 ③구조·관리·정책 용어가 모두 있어야 함 |
| 5. 과업 관련성 | 제목이 과업지시서 조항과 연결된 5개 주제 범주 중 하나 이상에 해당해야 함. 질병·임상 사례 등은 제외 |
| 6. 인용 검증 1차 | Crossref 등록 확인, 제목 유사도 0.9 이상, 연도 차 1년 이내, 제1저자 일치, 학술지명 존재, 철회·정정 기록 없음, doi.org 실존 확인 |
| 7. 재검증 2차 | 같은 검증을 독립적으로 다시 조회해서 1차와 결과가 완전히 같아야 함(재현성) |
| 8. 독립 재검토 | 최종 목록을 처음부터 다시 조회해 9개 항목을 글자 단위로 대조(`audit.mjs`) |

**환각 방지 원칙**
- 서지정보(제목·저자·연도·학술지·DOI)는 모두 Crossref(출판사가 등록한 정보)에서 그대로 가져왔어요.
- 정리표의 '연구 목적·방법·결과' 칸은 AI가 쓴 요약이 아니에요. 초록 문장을 **그대로 발췌**했고, `[초록 원문]` 표시를 붙였어요.
- 기준을 하나라도 통과하지 못하면 "애매한 자료"로 보고 제외했어요.

## 3. 한계 (꼭 읽어 주세요)

1. **"오류 0%"는 서지정보에 대한 검증 결과예요.** 논문이 실재하는지, 그리고 제목·저자·연도·학술지·DOI가 맞는지를 0건 불일치로 확인했다는 뜻이에요. 논문의 주장 자체가 옳은지까지 검증한 것은 아니에요.
2. **초록 발췌의 칸 분류는 자동이에요.** 문장은 원문 그대로지만, 어떤 문장이 '목적/방법/결과' 칸에 들어갔는지는 규칙으로 정했어요. 그래서 일부는 칸이 맞지 않을 수 있어요. 예를 들어 2012년 영국 센서스 논문은 '결과' 칸에 방법에 해당하는 문장이 들어갔어요. 인용 전에 원문을 확인해 주세요.
3. **국내 연구가 적게 잡혔어요(한국 관련 4건).** 국내 논문은 DOI가 없는 경우가 많아서 '원 출처 확인 불가'로 제외됐어요. KCI 검색 API는 KCI에서 발급하는 키가 있어야 해서 이번에는 쓰지 못했어요. 키를 발급받으면 국내 논문을 추가로 검토할 수 있어요.
4. **전수 검색은 아니에요.** 검색어별 관련도 상위 50건만 대상으로 했어요.
5. **주제 선별은 규칙(키워드) 기반이에요.** 누가 돌려도 같은 결과가 나오지만, 관련 논문을 빠뜨리거나 덜 관련된 논문이 들어갔을 수 있어요. 제외 사유는 `excluded.csv`에 모두 남겨 두었어요.
6. 과업지시서 자체는 연구 문서가 아니라 용역 계약 문서예요. 그래서 검색 주제(구조·포획, 보호센터 운영, 반환·등록, 정책)는 과업 내용에서 도출해서 정했어요.
